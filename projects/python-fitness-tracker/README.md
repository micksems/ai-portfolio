# Python Fitness Tracker

A command-line Python application for manual jump and repetition timing, training-plan-based weight recommendations, unit selection, and CSV logging.

## Materials

- [Python source code](fitness_tracker.py)

## Run locally

Requires Python 3. No external packages are needed.

```bash
python fitness_tracker.py
```

The app creates `Gym App.csv` in the working directory. Timing uses manual keyboard input, so jump height is an estimate.
